1. Variables in Python

Variables are containers for storing data values. Python has no command for declaring a variable; a variable is created the moment you first assign a value to it.

python_variables.py 
# Variable Assignment Examples
student_name = "Rahul Sharma"  # String
student_age = 20                # Integer
gpa = 3.85                      # Float
is_enrolled = True              # Boolean

print("Student:", student_name)
print("Age:", student_age, "| GPA:", gpa)
Output:
Student: Rahul Sharma
Age: 20 | GPA: 3.85

2. Python Data Types

Python built-in data types include integers (int), floating-point numbers (float), strings (str), lists (list), tuples (tuple), and dictionaries (dict).

data_types.py 
# Python Data Types
subjects = ["Python", "AI", "Machine Learning", "DSA"]  # List
student_profile = {"name": "Preethitha", "course": "BCA AI&ML", "semester": 3} # Dictionary
coordinates = (12.9716, 77.5946)                        # Tuple

print("Subjects List:", subjects[0:2])
print("Student Course:", student_profile["course"])
Output:
Subjects List: ['Python', 'AI']
Student Course: BCA AI&ML

3. Python Operators

Operators perform operations on variables and values. Common types: Arithmetic (+, -, *, /), Comparison (==, !=, >, <), and Logical (and, or, not).

operators_demo.py 
# Operators in Python
marks_python = 85
marks_ai = 90

total_score = marks_python + marks_ai
average = total_score / 2
is_distinction = average >= 85 and marks_python > 80

print("Average Score:", average)
print("Is Distinction:", is_distinction)
Output:
Average Score: 87.5
Is Distinction: True

4. Conditional Statements (if...elif...else)

Conditional statements control decision-making logic in programs based on specified boolean conditions.

conditions.py 
# Grade Evaluator Program
score = 88

if score >= 90:
    grade = "A+"
elif score >= 80:
    grade = "A"
elif score >= 70:
    grade = "B"
else:
    grade = "C"

print(f"Final Score: {score} | Grade: {grade}")
Output:
Final Score: 88 | Grade: A

5. Loops (for & while)

Loops are used to iterate over sequences (like lists or ranges) or execute code blocks repeatedly while a condition remains true.

loops_demo.py 
# Iterating over a list of AI topics
ai_topics = ["Neural Networks", "NLP", "Computer Vision"]

print("--- For Loop ---")
for topic in ai_topics:
    print("Studying:", topic)

print("\n--- While Loop ---")
count = 1
while count <= 3:
    print("Iteration:", count)
    count += 1
Output:
--- For Loop ---
Studying: Neural Networks
Studying: NLP
Studying: Computer Vision
--- While Loop ---
Iteration: 1
Iteration: 2
Iteration: 3

6. Python Functions

A function is a reusable block of code defined using the `def` keyword that executes only when called and can accept parameters and return values.

functions_demo.py 
# Function to calculate Euclidean distance (basic AI math helper)
import math

def calculate_distance(x1, y1, x2, y2):
    """Returns distance between two 2D points"""
    dist = math.sqrt((x2 - x1)**2 + (y2 - y1)**2)
    return round(dist, 2)

# Function call
d = calculate_distance(0, 0, 3, 4)
print("Distance between (0,0) and (3,4) is:", d)
Output:
Distance between (0,0) and (3,4) is: 5.0
